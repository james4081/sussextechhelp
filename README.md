# Sussex Tech Help

One-page website for Sussex Tech Help, a mobile computer repair and tech help service covering Bexhill-on-Sea, Hastings, St Leonards-on-Sea and Battle.

The site is a single static page in `docs/index.html` (CSS is inline, no build step). It is ready to serve with GitHub Pages from the `/docs` folder on the `main` branch. Open `docs/index.html` in a browser to preview it locally.

A light and dark theme toggle sits in the header. The choice is saved in the browser.
